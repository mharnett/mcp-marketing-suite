# MCP Marketing Suite

Run your ad accounts, analytics and tags from one Claude conversation. Eight Model Context Protocol (MCP) servers cover Google Ads, Microsoft Advertising, LinkedIn, Reddit, Meta, Google Analytics 4 (GA4), Search Console and Google Tag Manager (GTM): pull spend from three platforms, audit search terms and check tracking without switching between UIs.

Built by practitioners running real ad spend. Safe by default: write operations create items in PAUSED state, so nothing new serves until you turn it on.

```bash
claude plugin marketplace add mharnett/mcp-marketing-suite
claude plugin install google-ads@mcp-marketing-suite
```

## Map: which server for which job

| Job | Servers |
|-----|---------|
| **Campaign management**: create, pause, update and monitor campaigns | mcp-google-ads, mcp-bing-ads, mcp-linkedin-ads, mcp-reddit-ads, meta-ads-mcp |
| **Performance analysis**: spend, conversions, CPA, ROAS and custom breakdowns, compared across platforms | the ad-platform servers, plus mcp-ga4 |
| **Search term auditing**: review queries, add negatives, pause underperformers | mcp-google-ads, mcp-bing-ads |
| **Audience targeting**: interests, behaviors, demographics and geo on Meta; subreddits and interests on Reddit | meta-ads-mcp, mcp-reddit-ads |
| **Analytics**: GA4 reports (historical and realtime), Search Console search analytics and URL inspection | mcp-ga4, mcp-google-gsc |
| **Tag management**: list, create and update GTM tags, audit consent settings, preview in a sandbox workspace before publishing | mcp-gtm-ga4 |

Worked conversations: [weekly PPC review](examples/weekly-ppc-review.md) (Google Ads, Microsoft Advertising and GA4) and [cross-platform search term audit](examples/cross-platform-search-term-audit.md).

### Choose what you need (context matters)

**Don't install all eight.** Each MCP server's tool schemas are loaded into Claude's context window on every conversation, so every server you add costs context before you type a message. Pick the platforms you actually use; the suite is additive, not all-or-nothing.

## Install

### As Claude Code plugins

Each server is its own plugin, so you install only the platforms you use:

```bash
claude plugin marketplace add mharnett/mcp-marketing-suite
claude plugin install google-ads@mcp-marketing-suite
```

Plugins available: `google-ads`, `bing-ads`, `linkedin-ads`, `reddit-ads`, `ga4`, `gsc`, `gtm-ga4`. Each reads its credentials from environment variables with the names listed in the server's README, so export them before starting Claude Code. The Meta server is Python and is not offered as a plugin.

### As standalone servers

Prerequisites: Node.js 18+ for the TypeScript servers, Python 3.10+ for meta-ads-mcp, and API credentials for each platform you use ([where to get them](#credentials-guide)).

```bash
# Ad platforms — pick what you actually run
npm install mcp-google-ads
npm install mcp-bing-ads
npm install mcp-linkedin-ads
npm install mcp-reddit-ads
pip install meta-ads-mcp

# Analytics & tracking — pick what you actually use
npm install mcp-ga4
npm install mcp-google-gsc
npm install mcp-gtm-ga4
```

Then add the servers to your `.mcp.json`:

```json
{
  "mcpServers": {
    "google-ads": {
      "command": "npx",
      "args": ["mcp-google-ads"],
      "env": {
        "GOOGLE_ADS_CLIENT_ID": "your-client-id",
        "GOOGLE_ADS_CLIENT_SECRET": "your-client-secret",
        "GOOGLE_ADS_REFRESH_TOKEN": "your-refresh-token",
        "GOOGLE_ADS_DEVELOPER_TOKEN": "your-dev-token",
        "GOOGLE_ADS_CUSTOMER_ID": "123-456-7890"
      }
    },
    "ga4": {
      "command": "npx",
      "args": ["mcp-ga4"],
      "env": {
        "GA4_PROPERTY_ID": "your-property-id",
        "GOOGLE_APPLICATION_CREDENTIALS": "/path/to/service-account.json"
      }
    },
    "meta-ads": {
      "command": "meta-ads-mcp",
      "env": {
        "META_ACCESS_TOKEN": "your-access-token",
        "META_APP_ID": "your-app-id"
      }
    }
  }
}
```

**Security:** Never share your `.mcp.json` file or commit it to git -- it may contain API credentials. Add `.mcp.json` to your `.gitignore`.

Each server's setup page or README (linked in the [index](#index-every-server)) has its full configuration.

## Architecture

All TypeScript servers share a consistent architecture:

- **@modelcontextprotocol/sdk** for MCP protocol handling
- **Cockatiel** for resilience (retry with exponential backoff, circuit breaker, 30s timeout)
- **Pino** for structured JSON logging
- **200KB response truncation** to prevent context window overflow
- **Error classification** into auth, rate limit, and service errors with actionable messages
- **Safe by default** -- write operations create items in PAUSED state

```
User <-> Claude <-> MCP Server <-> Platform API
                        |
                   Resilience Layer
                   (retry, circuit breaker, timeout)
```

## How the index is kept honest

The index table and the profile costs are generated, never typed. `servers.json` says which servers the suite lists and where each one keeps its tool list (`src/tools.ts`). `npm run table:update` reads that file at the commit each server's latest npm release was published from, writes the tool names to `tool-lists.json` and rewrites the two generated blocks in this README. CI fails when the README and `tool-lists.json` disagree, or when a server has shipped a release whose tools `tool-lists.json` doesn't have yet; the fix is to run `npm run table:update` and commit both files.
